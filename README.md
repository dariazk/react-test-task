Структура:
- `src/features/catalog` — каталог, фильтры, карточка в списке
- `src/features/product` — карточка товара, выбор цвета/размера, галерея
- `src/features/cart` — контекст корзины, логика добавления, страница корзины
- `src/features/shared` — общие layout/страницы

Добавлены тесты на критичную логику:
- `cartReducer`:
  - добавление новой позиции
  - увеличение количества существующей позиции
- фильтрация/сортировка каталога (`getFilteredProducts`)
- построение уникальной позиции корзины (`buildCartItem`)

Дополнительные стейт менеджеры не подключала: для объёма тестового хватает Context + useReducer, без лишних зависимостей. Если понадобится внешний стор и попроще - можно брать Zustand. Redux Toolkit если приложение будет разростаться.
